An embedded bootstrapper still needs internet on a machine lacking WebView2; normal app operation was tested with an existing runtime. Local silent unsigned installation does not prove absence of Windows publisher/reputation prompts on a downloaded file. No security setting was bypassed. Signed distribution, updater and clean-machine release certification remain M15 requirements. This build makes no fully offline installation claim.
