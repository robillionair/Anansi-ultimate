## Planning findings and decisions

- The M2 placeholder still claimed M0 was current. Replaced that historical sentence with the actual M1 baseline and M2.0 approval gate; no milestone scope change.
- Markdown persistence and SQLite metadata require an explicit interruption protocol. Proposed immutable private revision files with hash checks followed by transactional pointer publication; orphan files never auto-import/delete. Search indexes alone are rebuildable, canonical metadata requires backup/export recovery.
- A selected-workspace backup cannot safely be a raw copy of the shared catalog. Proposed a standalone selected metadata snapshot with exactly referenced immutable bodies; full application backup stays a distinct disclosed scope.
- Privacy labels do not supply encryption. Initial slices reject Sealed, disclose plaintext limits and never infer disclosure consent. Audited optional vault remains in M2, with a mandatory M2.6 design approval and M2.7 implementation before certification.
- All source types/states/metadata, project/artifact envelope, six job states, export, manual/scheduled/versioned backup, preview/integrity/recovery and cross-cutting policies have task ownership. Later search/providers/ingestion/generated registry requirements remain assigned, not dropped. No product row marked verified.
