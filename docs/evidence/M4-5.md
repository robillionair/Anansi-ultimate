## Architectural design and cross-edition parity

1. **Cross-Edition Search Mode Selector (`packages/ui/src/Search.tsx`)**:
   - Offers 3 distinct search modalities via accessible native radio controls:
     - `Title only`: strict title keyword matching (bounded to 8 words, 256 bytes).
     - `Full-body search (includes Markdown text)`: rebuildable FTS5 BM25 search across Markdown titles and bodies with phrase and prefix support (bounded to 16 terms, 512 bytes).
     - `Hybrid semantic`: reciprocal rank fusion (RRF) combining lexical BM25 keyword rankings with pure Rust SIMD cosine vector similarity.
   - Explains privacy boundaries for each mode: strictly offline, zero network requests to AI providers, fail-closed exclusion of Sealed records.

2. **Grounded Evidence and RRF Score Breakdown**:
   - In hybrid mode, search results display:
     - Combined RRF fusion score (`RRF Score: 0.0328`).
     - Distinct lexical rank (`Lexical #1`) and semantic rank (`Semantic #2`).
     - Grounded section heading (`Section: # Architecture`) and starting line number (`line 42`).
     - Contextual snippet highlighting matching keyword evidence.

3. **HTTP and Tauri IPC Parity**:
   - Scoped HTTP endpoints registered in `crates/api/src/lib.rs`:
     - `POST /v1/ai/hybrid-search` -> `HybridSearchResponse`
     - `POST /v1/ai/context` -> `CompiledContext`
   - Tauri IPC commands routed in `crates/core/src/ai_discovery.rs` via `Core::ai_command`:
     - `"hybrid-search"` executes `hybrid_search` against the catalog connection.
     - `"context"` executes `compile_context` with section-level chunking and disclosure manifest generation.
   - Shared client implementation in `packages/contracts/src/client.ts` (`httpClient` and `nativeClient`) provides identical type-safe accessors `hybridSearch` and `compileContext` with runtime schema decoding.

4. **Fail-Closed Privacy Guarantees**:
   - Across all retrieval layers (FTS5 lexical index, in-memory cosine vector search, hybrid RRF fusion, multi-chunk context compiler, and Ask ANANSI grounded Q&A), records marked `privacy == "sealed"` are never indexed, searched, compiled, or transmitted.
   - Search queries remain local loopback only (`127.0.0.1`); zero telemetry, zero cloud inference.
