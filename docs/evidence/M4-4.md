## Architectural design and safety boundaries

1. **Multi-Chunk Section-Aware Context Compilation (`crates/core/src/context.rs`)**:
   - `chunk_markdown_sections`: chunks Markdown bodies into discrete section-based evidence blocks, capturing enclosing section headings (`# Heading`, `## Subheading`) and exact starting line numbers.
   - `compile_context`: invokes hybrid retrieval (`hybrid_search`), iterates over candidate records, performs fail-closed privacy verification, loads revision bodies, and chunks Markdown sections.
   - **Grounded Citations**: emits structured citations with 1-based indexing, section headings, line numbers, and preview snippets.
   - **Prompt Grounding**: builds a prompt requiring the model to answer using only the workspace evidence pack and cite each claim with `[n]`.

2. **Strict Budget Packing and Truncation**:
   - Configurable budget: defaults to 4,000 characters (~1,000 tokens), clamped to bounds `[500, 32,000]`.
   - Greedily packs evidence chunks. When a chunk exceeds the remaining character budget, it cleanly truncates the chunk to fill the remaining budget (preserving a minimum meaningful snippet of $\ge 50$ chars) and terminates compilation.

3. **Deterministic Chunk Deduplication**:
   - Tracks seen chunk contents across memories to eliminate verbatim repeated sections, ensuring diverse and high-value context density.

4. **Fail-Closed Privacy Boundary for Sealed Records**:
   - Resolves memory metadata across both production and mock schemas.
   - Any record marked `privacy == "sealed"` is strictly excluded from evidence chunks, citations, disclosure manifests, and compiled prompts.

5. **Disclosure Manifest ("View What ANANSI Sent")**:
   - Emits an inspectable `DisclosureManifest` logging runtime kind (`localLoopback`), endpoint, model tag, character count, estimated tokens, source memory references, routing rationale, and the verbatim compiled prompt.

6. **Big Brain (AN-011) Deliberative Reasoning Specification**:
   - Authored `docs/designs/BIG_BRAIN_SPEC.md` resolving the AN-011 design gate.
   - Formalized 5-step deliberative reasoning state machine: Plan -> Retrieve -> Critique -> Execute -> Reflect.
   - Defined safety boundaries: maximum 10 reasoning cycles, cycle loop detection, zero-cost lock (pure local loopback inference by default), fail-closed sealed record exclusion, and transparent step-by-step disclosure.
