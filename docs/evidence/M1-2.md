## Implementation and trust boundaries

Rust core serde DTOs generate JSON Schema with schemars 1.2.3 and TypeScript with json-schema-to-typescript 16.0.0. Ajv 8.20.0 generates static response validators, avoiding runtime code compilation under CSP. Contract version 1 rejects unknown request fields and incompatible versions. Application/core versions come from workspace build metadata; API version is adapter metadata from its actual build, null in direct native responses. Both adapters delegate domain validation to the same core.

Axum 0.8.9/Tokio 1.53.3 binds only 127.0.0.1. POST /v1/readiness requires exact Host, browser Origin http://127.0.0.1:1420 and constant-time checked per-launch OS-random 256-bit bearer. OPTIONS discloses no data and permits only the single route/method/header set. No wildcard CORS, cookies, redirects, query credentials, arbitrary paths or process routes. Requests are bounded to 1024 bytes. Error details are sanitized.

Each launch writes a unique pairing.json outside source under the per-user data directory. The directory/file are protected before the secret is written: owner-only protected Windows DACL read back using the Windows security module; POSIX directory 0700/file 0600. Link/reparse ancestors and relative paths are rejected. Permission failures disable startup. This protects against other normal users, not administrators or malicious same-user processes. Tokens are entered manually into browser tab memory; inputs clear after pairing and no persistent storage is used. Graceful shutdown removes the session file; forced termination can leave an owner-only stale file whose token is invalid for a new launch. No automatic recursive cleanup.

Tauri 2.12.4/tauri-build 2.7.3 uses a local main-window capability for get_readiness only; no remote capability, shell or filesystem plugin. CSP permits the local IPC transport; the bundled application does not require the HTTP service. Test-only WebView2 debugging uses verifier process environment for non-elevated local hosts, or an explicit debug-build configuration override for elevated CI hosts. Normal desktop/release configuration contains no debugging flags; the test build never requests release mode.

React/React DOM 19.3.1, Vite 8.3.4, plugin-react 6.1.2, TypeScript 7.0.2, Playwright 1.64.1, Tauri JS API 2.12.4/CLI 2.12.3 are pinned in manifests and resolved by pnpm. Original geometric icons are reproducible with scripts/icon.mjs. Source tools remain tracked in scripts/.
