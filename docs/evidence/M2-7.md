## Implemented core subset

- Exact pins argon2 0.6.0 (zeroize enabled; unused default PHC/RNG features disabled), chacha20poly1305 0.11.0 (alloc and internal zeroize enabled; unused RNG default disabled), zeroize 1.9.1 and target-specific keyring 3.6.3. Production Argon2id v0x13 m65536/t3/p4; approved import bounds retained. One process-local KDF at a time, immediate Busy on contention, explicit higher-cost admission. Cross-process admission remains unimplemented.
- Guarded independent random DEK/recovery key, exact 130-byte context keyslots, owner/vault/generation/purpose checks, passphrase unwrap and recovery replacement of passphrase/recovery slots with read-back authentication. Existing independent backup copies remain decryptable by old keys; no revocation claim for those copies.
- Process-local caller/root/transport/context-scoped random handles with idle/absolute deadlines, epoch checks, lock/drop/restart rejection and guarded secret buffers. No secret serde/debug or frontend transport entry point. Durable epoch acquisition and publication fencing remain integration requirements.
- Internal Sealed allow/deny policy and Search filtering trait. The only supplied Search policy excludes Sealed; Search files are untouched. This policy module is not yet wired into existing domain commands.
- Explicit OS credential-store binding, selecting real native implementations rather than a global/default mock backend. Consent and authenticated context are required for storing a wrapped passphrase slot; no raw DEK/recovery/password is stored. Synchronous accesses serialize in-process. No automatic startup unlock.
- Bounded encrypted shadow-stage preparation with context-bound members, authenticated encrypted journal, hash/read-back verification, private managed paths, refusal of overwrite, explicit interruption and preserved partial staging/originals. Verification after unlock does not execute recovery or publish a generation. Caller must still acquire a coherent domain-validated complete-history/graph snapshot.
