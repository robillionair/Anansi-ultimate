# M4.1 — Local Embeddings and Pure Rust Vector Space

Status: verified implementation. Acceptance criteria defined in [the detailed plan](../../plans/PHASE-004-semantic-intelligence.md) before code. Milestone 2 integration is maintained intact; pure Rust, p=4, and the G1 audit gate remain unchanged.

Acceptance scope: deterministic local embedding generation and pure Rust vector space primitives. Bounded vector representations (up to 1536 float32 dimensions), L2-normalization, pure Rust cosine similarity, loopback embedding client for Ollama (`/api/embeddings`), SQLite embedding cache table (`memory_embeddings`), and fail-closed Sealed privacy boundary.

Authority: Master Spec §11, §19, §77–78; Requirements Matrix AN-005, AN-009, AN-018.

## Architectural design and safety boundaries

1. **Pure Rust Vector Primitives (`EmbeddingVector`)**:
   - `crates/core/src/vector.rs` implements vector math without heavy third-party dependencies:
     - **Dimension Bounds**: strictly enforced between 2 and 1536 float32 dimensions (covering standard local embedding models: 384, 768, 1024, 1536).
     - **Numerical Integrity**: rejects empty vectors, dimension mismatches, and non-finite floats (NaN, infinity).
     - **Metrics**: provides exact L2-norm calculation, vector normalization, dot product, and cosine similarity clamped to `[-1.0, 1.0]`.
     - **Binary Serialization**: provides fast little-endian IEEE 754 f32 binary encoding (`to_bytes`) and decoding (`from_bytes`), verified with `as_chunks::<4>()` and strict multiple-of-4 length validation.

2. **SQLite Embedding Cache (`memory_embeddings`)**:
   - Workspace SQLite storage initializes table `memory_embeddings`:
     - `workspace_id TEXT NOT NULL`
     - `memory_id TEXT NOT NULL`
     - `chunk_index INTEGER NOT NULL DEFAULT 0`
     - `model TEXT NOT NULL`
     - `dimension INTEGER NOT NULL`
     - `embedding BLOB NOT NULL`
     - `created_at TEXT NOT NULL`
     - `PRIMARY KEY (workspace_id, memory_id, chunk_index, model)`
   - Fast lookup index on `(workspace_id, model)`.
   - Idempotent upsert semantics (`ON CONFLICT ... DO UPDATE`).
   - Retrieval (`get_embedding`), listing (`list_embeddings_for_workspace`), and deletion (`delete_embeddings_for_memory`).

3. **Loopback-Only Ollama Embedding Client**:
   - Master Spec §7, §11, §67:
     - Pure Rust standard library `std::net::TcpStream` connecting strictly to loopback addresses (`127.0.0.1`, `localhost`, `[::1]`).
     - Non-loopback endpoints are fail-closed rejected with `VectorError::InvalidEndpoint` before sending any network traffic.
     - HTTP POST to `/api/embeddings` with input payload capped at 8,192 UTF-8 bytes.
     - Strict 10-second connect, read, and write timeouts.
     - Offline resilience: returns `VectorError::Offline` without crashing or throwing if the local server is unstarted.

4. **Fail-Closed Sealed Privacy Boundary**:
   - Master Spec §74, §78:
     - Sealed memories are strictly forbidden from embedding generation and cache storage.
     - `store_embedding` queries `memories.privacy`; if `privacy == 'sealed'`, it immediately rejects the operation with `VectorError::SealedRecordRefused` and stores 0 rows.
