# M4.2 — Vector Search and SQLite Cache Synchronization

Status: verified implementation. Acceptance criteria defined in [the detailed plan](../../plans/PHASE-004-semantic-intelligence.md) before code. Milestone 2 integration is maintained intact; pure Rust, p=4, and the G1 audit gate remain unchanged.

Acceptance scope: vector search ranking active workspace records by cosine similarity against a query embedding vector, SQLite cache synchronization, metadata filtering (excluding archived records), and fail-closed Sealed privacy exclusion.

Authority: Master Spec §11, §19, §77–78; Requirements Matrix AN-005, AN-020.

## Architectural design and safety boundaries

1. **Cosine Similarity Vector Search (`vector_search`)**:
   - `crates/core/src/vector.rs` implements in-memory cosine ranking over cached vector embeddings:
     - Joins `memory_embeddings` with `memories` on `workspace_id` and `id`.
     - Strictly queries active plaintext records: `WHERE m.archived = 0 AND m.privacy != 'sealed'`.
     - Deserializes binary vector blobs using `EmbeddingVector::from_bytes`.
     - Computes cosine similarity in pure Rust, clamped to `[-1.0, 1.0]`.
     - Filters candidates by optional minimum score (`min_score`).
     - Sorts descending by score, breaking ties stably by `memory_id`.
     - Bounded result pagination (clamped to 1..100).

2. **Transactional Cache Synchronization & Invalidation**:
   - When a memory is created, revised, archived, or restored:
     - `crates/core/src/search.rs` invokes `invalidate_embeddings` inside `sync_index_tx` in the same SQLite transaction.
     - Ensures stale embeddings from previous revisions are cleared before new content is queried.
     - Deleting or archiving a memory immediately removes its embeddings from active vector search.

3. **Fail-Closed Sealed Privacy Boundary**:
   - Master Spec §74, §78:
     - Sealed memories are strictly omitted from `vector_search` queries via SQL predicate `m.privacy != 'sealed'`.
     - Verified with a dedicated failure test injecting a sealed record embedding: the sealed record is never returned in search results.
