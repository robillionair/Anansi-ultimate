# ANANSI Ultimate Demo — cinematic scenes and entity chat

## Open the Windows demo

Use `ANANSI Ultimate Demo` on the Windows Desktop. The launcher uses only `E:/Anansi/previews/larp-cinematic/data`, a separate sample workspace named **LARP Demo**. It automatically opens that populated workspace and the Second Brain. Existing user workspaces are not automatically opened or imported. The executable and build cache are on E:.

## Move around

In **01 Second Brain**, **03 Attention Spider** and **06 Orbital Collider**: drag to orbit, scroll to zoom, right-drag to pan. Arrow keys pan a focused canvas; Home or **Reset View** restores the camera. **Refresh Memory** reloads the actual workspace memory snapshot. The decorative particles do not represent extra memory records. Exit the observatory with **Exit** or Ctrl+Shift+L; the ordinary application remains available.

## Chat with the holographic entity

Select **07 ANANSI Entity**. The face has subtle depth, gaze, breathing, orbital light and response-driven jaw movement. Waiting and streaming animation follows the actual request state; it does not expose model thoughts or measured emotions. Reduced motion keeps the face static. A static portrait remains available without WebGL.

Open **Model connection**:

- **Workspace Ask · local runtime** uses the existing workspace-grounded Ask workflow. Choose the endpoint and an already-installed model. Each question is independently grounded; earlier conversation is not silently added to workspace evidence. Disclosure includes the actual compiled prompt and citations.
- **Configured provider / API** uses a model already configured in **AI Providers**. Enter its configured provider ID and model. This route sends only the bounded recent typed conversation, not workspace memories. Cloud transmission requires the checkbox for each Send; Zero-Cost Lock stays on. Keys are managed through the existing provider setup, never entered into the entity screen.

Nothing downloads or calls a model merely by opening the view. **Cancel reply** waits for the backend's run result. Switching scenes requests cancellation; **Resume watching backend run** is available if connectivity is lost. Changing a connection clears the transcript, preventing workspace-grounded answers from being carried into API chat. Chat history is session-only.

The demo contains sample knowledge, not an installed model or fabricated AI answers. An unavailable model produces an explicit offline/error state. No audio recording, speech synthesis, generated-software execution or paid inference is enabled by this delivery.
