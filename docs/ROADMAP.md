# ANANSI Ultimate — Roadmap

## Milestones

- **M0 — Foundation and recovery:** repository instructions, specification, matrix, architecture, plans, CI conventions.
- **M1 — Runnable shared shell:** React/Vite shared UI, Tauri shell, local API shell, design tokens, launch checks.
- **M2 — Core readiness vertical slice:** common contract, local persistence, one memory workflow, desktop/browser parity.
- **M3 — Memory OS:** schema, FTS5, embedded vector index, hybrid search, backup/restore.
- **M4 — Ask ANANSI:** context compiler, local provider adapter, consent and provenance.
- **M5 — Desktop release:** signed/unsigned build policy as approved, NSIS installer, clean-machine validation.
- **M6 — Provider and tool matrix:** AI Matrix, OAuth/API keys, MCP, Big Brain.
- **M7 — Advanced workflows:** Product Forge, LEXI-COLLIDER, SOMNIA, GHOST-PROMPT.
- **M8 — SwarmTank 3D:** Three.js visualization with performance and accessibility checks.
- **M9 — Enterprise/security-reviewed hosting:** multi-user architecture, tenancy, deployment, migration, threat review.

Milestones are dependency-ordered and subject to revision when the complete specification is restored.
